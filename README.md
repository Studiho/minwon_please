# 민원 플리즈: 건보 창구 5일

국민건강보험공단 OO지사 민원실 제3창구를 배경으로 한 **8비트 도트풍 서류 심사 웹 게임**입니다.  
외부 라이브러리나 별도의 이미지·사운드 파일 없이 **단일 `index.html` 파일** 하나로 동작하도록 제작되었습니다.

## 주요 특징
- **단일 파일 무의존성 실행**: HTML/CSS/JavaScript 및 Canvas·Web Audio API만으로 구현되어 브라우저에서 `index.html`만 열어도 바로 플레이할 수 있습니다.
- **신입 주임 이름 설정**: 게임 시작 시 이름(닉네임)을 입력하면 상단 HUD, 김 팀장 메신저, 민원인 대사, 퇴근 정산 및 엔딩까지 `○○ 주임` 호칭이 반영됩니다.
- **오늘 날짜 자동 연동**: 실행 시점의 오늘 날짜를 1일차로 잡아 5일차 일정과 신분증 유효기간·가족관계증명서 3개월 기준이 자동 계산됩니다.
- **5일차 캠페인 & 종합감사**
  - 1일차: 직장가입자 자격 취득 신고
  - 2일차: 피부양자 등록 (가족관계증명서 3개월 이내)
  - 3일차: 대리인 방문 (위임장·대리인 신분증)
  - 4일차: 보험료 환급금 신청 (통장 사본 본인 명의)
  - 5일차: 보험료 분할납부 신청 + 종합감사 & 5종 엔딩
- **PC 및 모바일 터치 지원**: 서류 확대, 나란히 보기, 불일치 지적, 업무 매뉴얼 탭 전환을 마우스와 터치 모두로 조작할 수 있습니다.

## GitHub에 올리고 바로 플레이하기 (GitHub Pages)
1. 이 저장소에 `index.html`, `README.md`, `.nojekyll` 파일을 업로드합니다.
2. GitHub 저장소의 **Settings → Pages**로 이동합니다.
3. **Build and deployment**의 Source를 **Deploy from a branch**로 선택하고, Branch를 `main` / `/ (root)`로 지정해 저장합니다.
4. 잠시 후 생성되는 `https://<아이디>.github.io/<저장소이름>/` 주소로 접속해 바로 플레이할 수 있습니다.

> 안내: 게임에 등장하는 인물, 주민등록번호, 주소, 사업장 및 업무 규칙은 모두 가상의 데이터이며 게임 진행을 위해 단순화한 것입니다.
